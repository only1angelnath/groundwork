# Shared ABIs

Single source of truth for contract ABIs, generated by `forge build` in
`contracts/out/` and copied here after each contract change. The worker,
backend, and frontend all import from this directory so none of them can
drift out of sync with what's actually deployed.

Populated starting Phase 1, once `BillPay.sol`, `GroundworkASC.sol`, and
`CreditVault.sol` exist and compile.
